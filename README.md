# VELORA Fashion Website

A responsive static fashion storefront built with HTML, CSS and vanilla JavaScript for GitHub Pages.

## Included
- Home page
- Shop with category filters and sorting
- Product detail pages
- LocalStorage shopping bag
- WhatsApp order checkout
- About page
- Contact page
- Newsletter UI
- Responsive mobile navigation
- Custom VELORA logo
- GitHub Pages-ready structure

## Before publishing
1. Open `js/main.js`.
2. Replace `WHATSAPP_NUMBER` with the real VELORA WhatsApp number.
3. Replace placeholder contact details in `contact.html`.
4. Replace product images and prices in `js/products.js`.
5. Replace the `#` social links with real VELORA profiles.

## GitHub Pages
Create a public GitHub repository, upload the contents of this folder, then go to:
Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.

Your site will be available at:
`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

For a user site, name the repository:
`YOUR-USERNAME.github.io`
Then the site is:
`https://YOUR-USERNAME.github.io/`
